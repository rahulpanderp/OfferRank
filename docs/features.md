# Features

## Initial feature groups
- User features
- Offer features
- Context features
- User-offer interaction features
- Historical behavioral aggregates

## Examples
- User: income band, life stage, card usage score
- Offer: offer type, fee, reward type, expected margin
- Context: channel, placement, device, time of day
- Cross features: user risk segment x offer type, user spend band x cashback offer

## Feature principles
- Start with interpretable features
- Keep online/offline feature definitions aligned
- Prefer features available at ranking time
